Climate Policy Intelligence Platform

Explore, Analyze, and Understand Climate Policies using AI-powered metadata insights.

🔍 What This Tool Does

This tool ingests climate policy documents (PDFs), extracts section-wise content using NLP and LLMs, and generates structured metadata. It provides searchable summaries and analytical tags to aid researchers, policymakers, and policy experts.

🛠️ How to Use

  • Upload policy documents (coming soon via upload form)
  • Explore metadata on the explore page
  • Analyze section-wise summaries and filters

🧪 Methodology

  1. Extract raw text from PDF using OCR and PDF parsers
  2. Detect and tag sections using heuristics (e.g., headers like “###”)
  3. Pass sectioned content to LLM to generate structured JSON metadata
  4. Merge section metadata to build a policy-level summary and index
  5. Store the result in a searchable SQL database

📌 Assumptions

  • Policies follow identifiable headers (for sectioning)
  • LLM model is accurate in summarizing and tagging
  • Metadata generation is consistent across policies
  • Only public and official government policies are uploaded
